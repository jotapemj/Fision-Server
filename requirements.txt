# ==========================================================================
# Fision - requirements
#
# Direct dependencies at the versions validated in production (Python 3.12,
# Linux, RTX 3090). Every other package is pinned in constraints.txt.
# Upgrading any of them can change separation quality or speed; do it
# deliberately and re-test.
#
# 1. Install PyTorch SEPARATELY, first, from the index that matches the GPU
#    (see "Install" in README.md). It brings the CUDA 12 libraries that
#    faster-whisper also uses. RTX 20xx and newer:
#
#   pip install torch==2.13.0 torchaudio==2.11.0 torchvision==0.28.0 --index-url https://download.pytorch.org/whl/cu129
#
# 2. THEN:  pip install -r requirements.txt -c constraints.txt
#
# System dependencies (not pip):
#   sudo apt install ffmpeg build-essential python3.12-dev
#   (ffmpeg -> audio-separator and pydub ;
#    build-essential and python3.12-dev -> madmom is compiled on install)
# ==========================================================================
