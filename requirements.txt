# Fision - requirements

# Install PyTorch SEPARATELY, first, with the correct CUDA index. Installing
# torch from here would pull the CPU build (slow). For a modern GPU
# (e.g. RTX 4060 Ti):
#
#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
#
# (adjust cu128 to your CUDA version). THEN:  pip install -r requirements.txt
#
# System dependencies (not pip):
#   sudo apt install ffmpeg python3-tk
#   (ffmpeg -> audio-separator and pydub ; python3-tk -> the desktop GUI)
# ==========================================================================
